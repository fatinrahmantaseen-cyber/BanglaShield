# BanglaShield

AI-powered phishing and scam detection platform with a focus on Bangladesh.

## Project Goal

BanglaShield aims to help users identify potentially dangerous URLs and suspicious scam messages through machine learning and explainable risk analysis.

## Planned Features

- URL risk analysis
- Bangla and English scam-message analysis
- Explainable detection results
- Security analytics dashboard
- REST API
- Automated testing
- Public web deployment

## Technology Stack

- Python
- FastAPI
- scikit-learn
- Next.js
- TypeScript
- PostgreSQL

## Project Status

Early development.

## Responsible Use

BanglaShield is an educational cybersecurity project. Its predictions are intended to provide risk indicators, not guarantee that a website or message is safe or malicious.
